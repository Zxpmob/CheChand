# افزونه‌ی چی چند برای گوگل کروم

این افزونه کنار صفحه‌ی گوگل (google.com)، دو پنل شناور (راست و چپ) نشان
می‌دهد با قیمت لحظه‌ای طلا، ارز، رمزارز و پرتغییرترین‌های روز — دقیقاً
همان دیتای واقعی سایت اصلی (Navasan برای طلا/ارز، CoinGecko برای
رمزارز)، بدون نیاز به هیچ سروری.

## نصب برای تست شخصی (قبل از انتشار در فروشگاه کروم)

1. آدرس `chrome://extensions` را در کروم باز کنید.
2. گوشه‌ی بالا-راست، «Developer mode» (حالت توسعه‌دهنده) را روشن کنید.
3. دکمه‌ی «Load unpacked» را بزنید و پوشه‌ی همین افزونه (که این فایل‌ها
   داخلش هستند) را انتخاب کنید.
4. یک آیکن جدید کنار نوار آدرس کروم اضافه می‌شود. بزنیدش تا تنظیمات باز
   شود.
5. یک تب جدید باز کنید و به google.com بروید — باید پنل‌ها را کنار
   صفحه ببینید.

## قبل از انتشار عمومی، این‌ها را عوض کنید

1. **آدرس سایت**: در دو فایل `content.js` و `popup.js`، متغیر
   `CC_SITE_URL` / `SITE_URL` را از `https://example.com/` به آدرس
   واقعی سایتتان (بعد از آپلود روی گیت‌هاب یا دامنه‌ی خودتان) تغییر
   دهید.
2. **آیکن‌ها**: از همان آیکن‌های سایت اصلی (`icon-32.png`,
   `icon-192.png`, `icon-512.png`) استفاده شده؛ اگر خواستید عوضشان
   کنید، همین اسم‌ها را در پوشه‌ی `icons/` جایگزین کنید.

## فضای تبلیغاتی

هر پنل (اگر گزینه‌ی «نمایش فضای تبلیغاتی» در تنظیمات روشن باشد) یک
`<div class="cc-ad-slot" id="cc-ad-right">` یا `id="cc-ad-left"` دارد —
فعلاً فقط یک جای خالی با نوشته‌ی «فضای تبلیغاتی» است. برای وصل‌کردن یک
شبکه‌ی تبلیغاتی واقعی (مثلاً یکی از شبکه‌های تبلیغاتی ایرانی، یا کد
تبلیغ خودتان):

1. در `content.js`، تابع `ccAdSlot(slotId)` را پیدا کنید.
2. به‌جای متن «فضای تبلیغاتی»، کد HTML/تصویر/لینک تبلیغ خودتان را
   بگذارید — مثلاً:
   ```js
   function ccAdSlot(slotId) {
     return `
       <div class="cc-ad-slot" id="${slotId}">
         <a href="LINK_TBLIGH_SHOMA" target="_blank" rel="noopener sponsored">
           <img src="URL_TASVIR_TABLIGH" alt="تبلیغ" style="width:100%;border-radius:8px;">
         </a>
       </div>`;
   }
   ```
3. اگر شبکه‌ی تبلیغاتی‌تان یک اسکریپت جاوااسکریپت می‌خواهد (نه فقط یک
   لینک/تصویر ساده)، توجه کنید که افزونه‌های کروم قوانین سخت‌گیرانه‌ای
   درباره‌ی اجرای کد خارجی دارند (Content Security Policy) — بیشتر
   شبکه‌های تبلیغاتی معمولی (که برای وب‌سایت طراحی شده‌اند، نه افزونه)
   مستقیم کار نمی‌کنند و باید تصویر/لینک ثابت تبلیغ را خودتان از طرف
   تبلیغ‌دهنده بگیرید و مثل بالا نمایش دهید.

## انتشار در فروشگاه کروم (Chrome Web Store)

1. یک حساب توسعه‌دهنده در
   [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole)
   بسازید (هزینه‌ی یک‌بارِ حدود ۵ دلار ثبت‌نام دارد).
2. تمام فایل‌های این پوشه را zip کنید (خودِ فایل‌ها، نه یک پوشه‌ی
   داخل zip).
3. در Developer Dashboard، «New Item» را بزنید و همان zip را آپلود
   کنید.
4. اسکرین‌شات، توضیحات، و دسته‌بندی (Productivity یا Shopping) را پر
   کنید و برای بررسی ارسال کنید — بررسی گوگل معمولاً چند روز طول
   می‌کشد.

## محدودیت‌های مهم

- این افزونه فقط روی صفحات `google.com` فعال می‌شود (طبق تنظیمات
  `matches` در `manifest.json`)؛ اگر خواستید روی موتورهای جستجوی دیگر
  (Bing، یاهو و…) هم کار کند، باید `matches` را در `manifest.json`
  گسترش دهید.
- روی صفحه‌های کوچک (کمتر از ۱۴۰۰ پیکسل عرض) پنل‌ها مخفی می‌شوند تا جای
  نتایج جستجوی گوگل را تنگ نکنند — این را می‌شود در `content.css`،
  بخش `@media` عوض کرد.
- دیتا مستقیم از مرورگر کاربر گرفته می‌شود (نه از یک سرور واسط)، پس
  همان محدودیت‌های فیلترینگ/نرخ درخواست که در سایت اصلی توضیح داده شده
  (README اصلی سایت) اینجا هم صدق می‌کند.
